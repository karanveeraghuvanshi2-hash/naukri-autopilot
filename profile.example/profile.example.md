# Profile

Facts that answers are derived from. `/naukri-setup` builds `profile/profile.md`
(private) from the resume, and the user confirms every row. A skill missing
from the skill table means "No" and 0 years.

  `profile/preferences.toml` (career start minus gap months). Answer in the

- Highest education:
- Resume on Naukri: file name and upload date
